# 🔐 Advanced Cryptography Suite in C++

A menu-driven C++ application that demonstrates fundamental cryptographic algorithms and secure communication concepts.

## 📌 Features

### 1. RSA Cryptosystem
- Public-key encryption and decryption
- Key generation using prime numbers
- Secure message encryption

### 2. Diffie-Hellman Key Exchange
- Secure shared key generation
- Demonstrates key exchange over an insecure channel

### 3. Hashing
- Generates unique fingerprints for input data
- Used for integrity verification

### 4. File Security
- Encrypts and decrypts messages
- Verifies data integrity using hashing

### 5. Merkle Tree
- Generates Merkle Root from multiple transactions
- Demonstrates blockchain-style integrity verification

### 6. Hill Cipher
- Matrix-based classical encryption algorithm
- Uses linear algebra concepts for encryption

### 7. Graph Algorithms
- Implements Dijkstra's Algorithm
- Demonstrates shortest path computation in networks
